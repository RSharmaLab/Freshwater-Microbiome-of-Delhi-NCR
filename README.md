# Freshwater-Microbiome-of-Delhi-NCR
Freshwater genome-resolved catalog of 61 water bodies across Delhi-NCR region.
01_Read_based_profiling holds all the R scripts used for the analysis related to the read based work, including the community and diversity comparisons, linear regression models, envfit analysis etc.
02_MAG_work holds R scripts related to MAG based comparisons between water body groups, function enrichment analysis, CAZyme repertoire analysis etc.
